Class Roll Call

The system defines three distinct user roles with cleanly isolated permissions.

01 Admin

Platform management and enrollment. Creates institutional classes, registers teacher accounts, manages bulk CSV enrollments, and reviews institution-wide performance reports.

No question authoring or grade manipulation privileges.
02 Teacher

Topic ownership and exam control. Authors MCQ and coding problems, coordinates class visibility, schedules exams, and watches real-time student anti-cheating streams.

Complete control over topic mapping and grade release.
03 Student

Secure attendance and coding. Joins timed examinations using generated codes, uses the in-browser code editor, and accesses assigned topics for self-paced practice.

Sees only topics assigned to their designated class.

Sandboxed Execution

Each code submission runs inside a fresh Docker container. Network interfaces are shut down to prevent exfiltration or external payloads.

Hidden Test Cases

Students test code against public test cases for reference, while grading evaluates solutions against hidden test cases to prevent hardcoded outputs.

Container-level Limits

CPU execution timers and RAM limits (e.g. 256MB) are enforced directly at the container level to safely terminate infinite loops and leaks.

Mixed Question Papers
